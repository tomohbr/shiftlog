## 審査用デモアカウント（Guideline 2.1・必須）

ログインが必要なアプリは、審査員が使えるアカウントの提出が必須。**空のアカウントを渡すと「機能を確認できない」で却下される**ため、シフト・スタッフ・打刻データを入れた状態で用意する。

```
【管理者ログイン】
メールアドレス: （審査用に作成）
パスワード: （審査用に作成）

【スタッフのPINログイン】
会社PIN: （審査用に作成）
※ ログイン画面の「PINでログイン」から会社PINを入力し、
   表示されたスタッフ一覧から名前をタップしてください。

【キオスク打刻の確認方法】
会社PIN入力 → スタッフ選択 → 出勤/退勤ボタン
```

審査メモには、あわせて **ネイティブ機能の説明**を書く（Guideline 4.2 対策）:
- オフライン時でも打刻でき、通信復帰時に自動同期されること
- シフト確定・交代依頼をプッシュ通知で受け取れること
- Face ID でログインできること
- ホーム画面ウィジェットで当日のシフトを確認できること

## スクリーンショット

### 必要なサイズ

- **iPhone 6.9インチ: 必須**（1320×2868 / 1290×2796 / 1260×2736 のいずれか、縦向き）
- iPad 13インチ: iPad 対応にする場合のみ必須
- 1〜10枚

### 現状

`store-assets/screenshots/` にある7枚は **1080×2338（Android向け）で、App Store には使えない**。撮り直しが必要。

### 撮り直しの方法

`take-screenshots-ios.js` を用意してある（Node インストール後に実行可能）。

```bash
cd ~/カンパニー/shiftlog/store-assets
npm install puppeteer
node take-screenshots-ios.js
```

viewport 440×956 × deviceScaleFactor 3 = **1320×2868** で出力される。
